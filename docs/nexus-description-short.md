# Nexus 短描述（mod 卡片用）

**Mod 名**：
```
Lumine (Genshin Impact) - Terran Female NPC Replacer
```

**一句话简介**：
```
Genshin Impact's Lumine replaces the Terran female NPC models in X4: Foundations.
```

**功能列表**（英文，可直接粘贴）：
```
Lumine (Genshin Impact) - Terran Female NPC Replacer

Replaces the Terran female NPC models in X4: Foundations with Lumine from
Genshin Impact.

- Custom model, textures and materials for Lumine
- Built on the vanilla shared skeleton and animation set: animations, look-at
  and hand attachment points all work normally
- Covers Terran and Pioneer faction women, including the story and mission
  characters that never appear in a random appearance pool
- No game files modified; enable or disable at any time and saves stay valid
- Already included in the two back-ported fixes: the face/hair/cloth atlases
  are the right way up, and the textures ship with full mip chains

Note: unlike the Argon replacers, this mod does NOT touch Argon women -- it
replaces the Terran race. It can be run alongside them.

Requires X4: Foundations 9.00 (and the Cradle of Humanity DLC, which is where
the Terran race comes from).
```

**中文版功能列表**（供中文页面用）：

荧（原神） - 泰伦女性 NPC 外观替换

把《X4：基石》里的泰伦（Terran）女性 NPC 外观替换为《原神》的荧。

- 覆盖泰伦与先锋两个势力的女性，**包含从不出现在随机外观池里的剧情/任务 NPC**
- 不修改任何游戏原始文件，可随时启用/停用，存档安全
- 已包含两项回填的修复：面部/头发/服装贴图朝向正确，且贴图带完整 mip 链

注意：与阿贡（Argon）女性替换 mod 不同，本 mod **不碰 Argon 女性**，
