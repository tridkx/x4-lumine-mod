# Nexus 短描述（mod 卡片用）

**Mod 名**：
```
Lumine (Genshin Impact) - Terran Female NPC Replacer
```

**一句话简介**：
```
Genshin Impact's Lumine joins (or replaces) the Terran female NPC models in X4: Foundations.
```

**三个下载，三种配置**（文件名即配置，泰伦的两种二选一；阿贡版可以一起装）：
```
x4_lumine_terran_add_v1.4.zip      泰伦 / 先驱者女性 · 加入外观池（正常游玩用这个）
x4_lumine_terran_replace_v1.4.zip  泰伦女性 · 全部替换（含剧情/任务 NPC，测试用）
x4_lumine_argon_add_v1.4.zip       阿贡女性 · 加入外观池（同一个模型，换目标种族）
```

**功能列表**（英文，可直接粘贴）：
```
Lumine (Genshin Impact) - Terran Female NPC Replacer

Brings Lumine from Genshin Impact into X4: Foundations as a female NPC model.
Three files; the name says which shape you downloaded.

- x4_lumine_terran_add_v1.4.zip (normal build) -- Lumine joins the 12 Terran and
  Pioneer female appearance pools as one more random candidate, about one in
  four of the women a pool spawns. Every vanilla model stays, so the other
  women keep their own faces, names and voices. Story and mission NPCs keep
  their vanilla appearance (they never come from a pool).
- x4_lumine_terran_replace_v1.4.zip (test build) -- all 45 Terran-race female
  NPC macros are re-pointed at Lumine, so every Terran and Pioneer woman is her,
  story and mission NPCs included.
- x4_lumine_argon_add_v1.4.zip -- the same model written into the 6 Argon female
  pools instead. Installable alongside the Terran build; it shares those pools
  with the other Argon replacers (Rose, Emilie, ...), so the last one loaded
  wins there.

All builds: custom model, textures and materials; built on the vanilla shared
skeleton and animation set, so animations, look-at and hand attachment points
work normally; no game files modified, enable or disable at any time and saves
stay valid; the face/hair/cloth atlases are the right way up and the textures
ship with full mip chains.

Requires X4: Foundations 9.00. The Terran builds also need the Cradle of
Humanity DLC; the Argon build does not.
```

**中文版功能列表**（供中文页面用）：
```
荧（原神） - 泰伦女性 NPC 外观

把《原神》的荧做成《X4：基石》里的女性 NPC 外观。三个文件，文件名即配置。

- x4_lumine_terran_add_v1.4.zip（正式版）：荧加入泰伦与先驱者的 12 个女性外观池，
  是随机出现的其中一个（池里原本 3 个候选，约占 1/4）。原版模型全部保留，其余女性
  保持自己的脸/名字/语音；**剧情/任务 NPC 不走外观池，保持原版**。
- x4_lumine_terran_replace_v1.4.zip（测试版）：45 个泰伦女性 macro 的模型逐个改成荧，
  所以每个泰伦与先驱者女性都是她 —— **包含剧情/任务 NPC**。
- x4_lumine_argon_add_v1.4.zip：同一个模型写进阿贡女性的 6 个池。可与泰伦版同时安装；
  它和萝丝/艾梅莉埃等阿贡外观 mod 争同一批池，按加载顺序互相覆盖。

共同点：自建模型/贴图/材质；沿用原版共享骨架与全套共享动画（动作、注视、手持挂点
正常）；不修改游戏原始文件，存档安全；面部/头发/服装贴图朝向正确且带完整 mip 链。

需要 X4: Foundations 9.00；泰伦的两个版本还需要《人类的摇篮》DLC，阿贡版不需要。
```
